## 💼 O que tenho construído

**Controle de Lacres** — App de campo (PWA) para auditoria de lacres de bicos de abastecimento. Garante rastreabilidade de quem validou, quando e com qual método; exige foto como evidência obrigatória para lançamentos manuais; e previne dupla validação por concorrência via chave primária composta no Oracle — dois aparelhos tentando o mesmo lacre ao mesmo tempo: o segundo recebe `409`, sem precisar de lock de aplicação. `Vue 3 · Node.js · Oracle thick mode · Docker`

**FrotaFuel** — Plataforma de cotas de combustível que ingere dados diários do ERP Oracle corporativo, versiona cotas semanais com histórico imutável (window functions + soft-close) e exibe alertas de consumo em tempo real (Normal → Alerta → Excedido). Autenticação integrada ao Active Directory com RBAC de três níveis. `React 19 · Express · Oracle · LDAP/AD · Docker`

**Desponte de Cana** — Sistema de avaliação de qualidade de cargas em duas fases: apontamento compartimento a compartimento com evidências fotográficas obrigatórias, e reconciliação posterior com tickets do ERP. A quantidade de compartimentos avaliados precisa bater exatamente com os itens do ticket antes de qualquer gravação. `Next.js · Oracle thick mode · NextAuth · TypeScript`

**Festa Manager** — Sistema de gestão para locação de festas com trava de estoque garantida por trigger no banco: overbooking é recusado mesmo em acesso direto à tabela. Financeiro em centavos inteiros (sem float), mobile-first, PWA instalável no iPhone. Open source. `Next.js 14 · Supabase · PWA · TypeScript`
